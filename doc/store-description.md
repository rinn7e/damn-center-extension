# Store Listing Text

The text for the Chrome Web Store and Firefox Add-ons listings. Both stores show plain text, so copy the contents of each block as-is. Keep it in line with the README's feature list and [PRIVACY.md](../PRIVACY.md).

## Short description

Chrome allows 132 characters; this is also the `description` in the manifests.

```text
Center any website on your widescreen or ultrawide monitor, with per-site padding, rulers, themes and background patterns.
```

## Full description

```text
Many websites hug the left edge of the screen. On a widescreen or ultrawide monitor, that means reading with your head turned. Damn Center adds padding beside the page to bring its content to the center of your screen, and remembers your setup for each site.

FEATURES

• Per-site matches: save different settings for each site, or for parts of a site, using URL patterns. "+ New Match" adds a rule for the current page in one click, and a domain switch turns a whole site on or off.
• Width and side: set the padding width with a slider, on the left, the right or both sides.
• Layout-safe: the page is shifted with CSS Flexbox, so the padding never covers content and sticky headers stay in place.
• Colors and patterns: fill the padding with a color or a pattern (grid, dots, stripes, carbon or lattice), with separate light and dark versions that follow your system or a mode you choose.
• Alignment ruler: show guide lines at 25%, 50% and 75% of the window.
• Steps aside when needed: pauses while a video or page is fullscreen. Optionally, it also pauses whenever the window isn't maximized, for example when you tile windows side by side.
• Backup: export all your settings to a file and import them on another browser or computer.
• Adjustable popup: scale the popup text from 12 to 32 px.

PRIVACY

Damn Center collects no data and makes no network requests. Your settings stay on your device.

Open source (GPL-3.0): https://github.com/rinn7e/damn-center-extension
```
