# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep
discussion about the work. Harassment, insults and personal attacks aren't
accepted in issues, pull requests or any other project space.

## Reporting

Report unacceptable behavior privately to the maintainer,
[@rinn7e](https://github.com/rinn7e), through the contact details on their
GitHub profile. Reports are kept confidential. The maintainer may edit or
remove comments, close threads, or block anyone who breaks this code.
